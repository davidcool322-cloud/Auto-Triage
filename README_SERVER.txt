# Hyper-RMA 伺服器連線說明

本電腦目前正在運行 **Hyper-RMA 診斷伺服器**。
只需透過瀏覽器即可存取所有功能，無需安裝任何軟體。

## 🚀 如何連線

請在您的瀏覽器 (Chrome / Edge) 網址列輸入以下網址：

    http://10.192.100.68:8501

*(若您的瀏覽器顯示不安全警告，請忽略並繼續前往)*

## 🔑 登入資訊
- **使用者名稱**: USER
- **密碼**: USER

## 📌 注意事項
1. **請勿關閉主機**: 此網頁依賴伺服器電腦運作，若電腦關機或休眠，網頁將無法連線。
2. **多人使用**: 系統支援多人在不同電腦同時操作，但請留意不要同時對**同一台 BMC** 下達衝突指令。
3. **網路限制**: 本服務限制於公司內網 (Intranet) 使用，請確保您的 VPN 已連線或位於辦公室網路環境。
